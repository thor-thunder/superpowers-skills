## Using References

When learning about a skill or writing new skills, consult these references:

1. **For Writing:** Check `conventions/` for style and formatting guidelines
2. **For Setup:** Check `patterns/` for deployment and testing examples
3. **For Attribution:** Check `attribution/` for sources and authors
4. **For Learning:** Follow links to original sources and foundational work

## Contributing

To add reference material:

1. Place examples in appropriate subdirectory (`conventions/`, `patterns/`, or `attribution/`)
2. Use clear filenames that indicate content
3. Include introductory section explaining context and purpose
4. Add reference to this README
5. Link from related skill documentation

---

## Document Structure

All reference documents should include:

1. **Title** - Clear description of content
2. **Purpose** - Why this document exists and when to use it
3. **Related Skills** - Links to relevant skills
4. **Content** - Main material, examples, or attribution
5. **Attribution** - Sources and authors for attribution docs
