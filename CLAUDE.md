# Superpowers Skills

A collection of powerful skills and tools for Claude Code, extending Claude's capabilities for specialized tasks.

## Project Overview

This repository contains skill implementations that enhance Claude's ability to handle complex workflows, including atomic operations, task management, and advanced development tools.

## Skills Activated

### Core Skills
- **atomic-agents**: Atomic operation management for reliable, transactional workflows
- **superpowers-skills**: Extended skill set for advanced development tasks

### Development Skills
- **init**: Initialize a new CLAUDE.md file with codebase documentation
- **review**: Review pull requests with comprehensive analysis
- **security-review**: Complete security audits of pending changes
- **simplify**: Review and optimize code for quality and efficiency
- **fewer-permission-prompts**: Reduce permission prompts by configuring allowlists

### Utility Skills
- **session-start-hook**: Set up startup hooks for Claude Code on the web
- **update-config**: Configure Claude Code settings and environment
- **keybindings-help**: Customize keyboard shortcuts and bindings
- **claude-api**: Build, debug, and optimize Claude API applications
- **loop**: Run commands on recurring intervals
